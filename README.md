# Netflix Clone

This is a front-end clone of the Netflix website, built using HTML5 and CSS3. The project replicates the design and structure of Netflix's homepage to practice web development fundamentals, layout techniques, and responsive design.

## Technologies Used

HTML5 – for page structure  
CSS3 – for styling and layout  
Google Fonts

## Features

Netflix-style navbar with logo, search, and profile icons  
Movie and TV show sections with grid layout  
Category banners and promotional sections  
Responsive design for better mobile viewing  
Footer similar to the real Netflix site

## Folder Structure

Netflix-clone/
├── Netflix-clone.html

└── images/

## What I Learned

Structuring HTML for complex layouts  
Styling large websites with modular CSS  
Responsive design using Flexbox and Grid  
Using real website clones as design references
